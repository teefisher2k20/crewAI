# Palette's Journal - Flow Visualization UX & Accessibility

## 2025-05-15 - Improving Accessibility and Semantics in Flow Visualization
**Learning:** Interactive elements should always use semantic tags like `<button>` instead of `<div>` to ensure they are properly recognized by screen readers and are keyboard-accessible by default. Proper ARIA labels and focus indicators are crucial for an inclusive user experience.
**Action:** When working with visualization tools or dashboards, audit all interactive elements for semantic correctness and accessibility attributes. Ensure focus states are clearly visible for keyboard users.
