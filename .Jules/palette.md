## 2025-05-15 - [Semantic Buttons and Focus Indicators in Visualization Components]
**Learning:** In interactive visualizations built with non-standard components (like network graphs and custom side panels), standard interactive elements like navigation controls are often implemented as `div` or `span` for styling ease, which breaks keyboard accessibility and screen reader support. Using semantic `<button type="button">` with explicit `aria-label` and brand-consistent `:focus-visible` outlines ensures the UI is accessible while maintaining the desired aesthetic.
**Action:** Always prefer semantic `<button>` for navigation and action triggers. Ensure icon-only buttons have descriptive `aria-label` attributes. Implement clear focus indicators using brand colors to assist keyboard users.
