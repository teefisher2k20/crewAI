# Palette's Journal - CrewAI UX & Accessibility

## 2026-06-29 - [Initial UX Review]
**Learning:** The Flow visualization interface uses several icon-only 'div' elements as buttons, which are not semantic and lack accessible labels for screen readers. Additionally, interactive elements lack distinct focus states for keyboard-only users.
**Action:** Transition icon-only controls to semantic buttons, add proper ARIA labels, and implement high-contrast focus indicators.
