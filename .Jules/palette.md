## 2025-05-15 - [CLI Onboarding Improvements]
**Learning:** Users often feel lost after a "successful" CLI operation if they aren't given immediate, actionable next steps. Providing a styled guidance panel directly after project creation significantly improves the onboarding experience and reduces cognitive load.
**Action:** Always include a "Next Steps" or "What's Next" section after any command that sets up a new environment or project structure.

## 2025-05-15 - [Consistent Styling in CLI]
**Learning:** Using a centralized console object and standard libraries like `rich` ensures that micro-UX improvements (like styled version labels) feel like a cohesive part of the tool rather than disconnected additions.
**Action:** Funnel all styled CLI output through a common utility to maintain visual consistency and ease of maintenance.
