## 2025-05-15 - [Improving Accordion Accessibility]
**Learning:** Using semantic `<button>` elements for accordion headers instead of `<div>`s provides native keyboard support (Enter/Space) and allows for standard ARIA attributes like `aria-expanded` and `aria-controls`.
**Action:** Always use semantic buttons for interactive elements that toggle visibility, and explicitly manage focus when opening side panels or drawers to improve screen reader and keyboard navigation flow.
