## 2025-05-22 - Semantic Controls and Focus Management in Flow Visualizations
**Learning:** In interactive data visualizations like the CrewAI Flow graph, complex controls (zoom, theme, export) implemented as `div` elements are invisible to screen readers and keyboard users. Converting these to semantic `<button>` elements with clear `aria-label` attributes and `:focus-visible` styles significantly improves the accessibility of the overall experience without requiring a full UI redesign. Synchronizing `aria-label` with state changes (e.g., light vs. dark mode) is critical for non-visual users to understand the current action available.
**Action:** Always prefer semantic HTML tags over `div` for interactive elements and ensure all icon-only controls have persistent or dynamic ARIA labels.
